# Support

Latent Trace is an independently maintained research project at
[latenttrace.org](https://latenttrace.org). Contact Courtney Hammond at
[courtney@latenttrace.org](mailto:courtney@latenttrace.org).

For a reproducible software bug, use the repository's bug-report form. Include
the affected version, steps, and a sanitized error message. Do not attach
database dumps, credentials, private correspondence, or personal case details.

Send security reports privately using [SECURITY.md](SECURITY.md). Send requests
to correct or remove case information by email, with the page URL and the
minimum information needed to locate the record. Do not post those requests
in public issues.

Latent Trace is not a law-enforcement agency or a tip line. Send investigative
information to the agency identified on the original source page. For an
emergency, contact your local emergency service.

Support is provided as time permits; there is no guaranteed response time.
